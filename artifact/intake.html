Account Composition Intake

Paste the LinkedIn request, name the account, press Run composition. The research agents read the ledger, crawl the company's site and the open web, draft the SMI prequalification proposal and file it into the CRM (the contact's notes, or the account's for a new prospect); the note to the founder shows up below. This is the only way proposals are made. Nothing to copy into a terminal.

Composed accounts have to land somewhere. Choose before running, because the two paths mint different record ids.

Check before choosing Apollo. Account ingest reads the lists in meta/config.account_lists. The Strategic Market Insights list was re-added on 24 Sep 2026. The run reads that setting first; if it is ever empty again the founder note HOLDs until the list id is back or you switch to manual.

Run

One press writes the run record and wakes the session that owns the repo. In order: re-gate the manifest → ledger tools → the company's site → Apollo and Vibe Prospecting → open-web research (company, market, competitors, adjacent, macroeconomics) → the SMI proposal with a ValueFirst "why now" → founder note → one merged note into the CRM record's pre-qual phase, with the Apollo and CRM sync schedule that follows.
